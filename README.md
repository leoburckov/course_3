HH Vacancies
Проект для сбора и анализа вакансий с HeadHunter API. Позволяет получать данные о вакансиях и работодателях, сохранять их в базу данных и анализировать.

Основные возможности
📊 Получение данных о вакансиях с HH API

💼 Работа с информацией о работодателях

🗄️ Сохранение данных в PostgreSQL

📋 Анализ и фильтрация вакансий

🎯 Поиск по различным критериям# course_3
